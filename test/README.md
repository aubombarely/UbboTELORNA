# UbboTELORNA — Test Data

## Synthetic test genome

`test_genome.fasta` — 4 sequences, 6,008 bp total.  
Generated by `make_test_data.py` with `random.seed(42)`.

| Sequence | Length | Content | Tests |
|---|---|---|---|
| `seq1_telomeric` | 2,420 bp | 30× TTTAGGG + 2,000 bp random + 30× TTTAGGG | Module 0 telomere detection |
| `seq2_rRNA` | 1,116 bp | 500 bp random + 5S rRNA (121 bp, RF00001) + 500 bp random | Module 2 rRNA annotation |
| `seq3_tRNA` | 672 bp | 300 bp random + tRNA-Phe/GAA (73 bp) + 300 bp random | Module 3 tRNA annotation |
| `seq4_lowcomplex` | 1,800 bp | AC×200 + 1,000 bp random + AC×200 | Module 1 masking robustness |

## Expected outputs

### Module 0 — Telomere identification
- `seq1_telomeric` should yield 2 telomere features (5′ and 3′ ends)
- `seq4_lowcomplex` may yield telomere-like calls (AC repeat is detectable) —
  this is expected behaviour; masking prevents it from interfering with rRNA/tRNA search
- Auto-detected repeat unit: `TTTAGGG` (canonical form may appear as `CCCTAAA`)

### Module 2 — rRNA annotation (requires internet on first run)
- `seq2_rRNA` should yield 1 hit for `5S_rRNA` (RF00001)
- cmsearch downloads Rfam CMs to `~/.ubbotelorna/rfam/` on first run (~300 KB)

### Module 3 — tRNA annotation
- `seq3_tRNA` should yield 1 hit: `tRNA-Phe(GAA)`, plus strand

## Quicktest

```bash
conda activate ubbotelorna

# Full test (requires internet for first Rfam CM download)
python3 scripts/UbboTELORNA.py \
    --fasta  test/test_genome.fasta \
    --output test_run/ \
    --kingdom euka \
    --threads 2

# Offline test (skip rRNA, no internet needed)
python3 scripts/UbboTELORNA.py \
    --fasta        test/test_genome.fasta \
    --output       test_run_offline/ \
    --skip_module2 \
    --threads 2
```

## Regenerate test data

```bash
python3 test/make_test_data.py
```

Uses `random.seed(42)` for reproducibility. The embedded 5S rRNA and tRNA-Phe
sequences are fixed biological sequences, not randomly generated.
